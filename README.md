# מרוץ המספרה 🏃✂️ — אבי × קוקו

משחק ריצה אינסופית מקורי בהשראת משחקי ריצה בסגנון Temple Run, מותאם למובייל ולעברית (RTL).

## משחק אונליין

https://shalevg12.github.io/templeRunMaspera/

## שלט QR להדפסה

https://shalevg12.github.io/templeRunMaspera/qr.html

## איך משחקים

1. בוחרים לשחק בתור אבי (ספר הנשים) או קוקו (ספר הגברים).
2. לוחצים על **יאללה לרוץ**.
3. מחליקים ימינה או שמאלה כדי לעבור נתיב; למעלה כדי לקפוץ; למטה כדי להתכופף.
4. אפשר גם ללחוץ על ארבעת הכפתורים בתחתית המסך.
5. קופצים מעל כיסאות, מתכופפים מתחת למחסומי המספריים, ומתחמקים מעגלות הספר.
6. אוספים מטבעות; מתחילים עם שלושה לבבות. הניקוד והשיא נשמרים בדפדפן.

## פרסומות משותפות

המשחק טוען את `barberCommon/ads.js?v=2` מתוך `barber-battle`. הפרסומת מופיעה אחרי כל **שתי ריצות שהסתיימו בפסילה** (אובדן כל שלושת הלבבות), לא במהלכה. זמן הדילוג: 5 שניות בצפייה הראשונה, 3 בשנייה, ומיד מהשלישית ואילך. כפתור **"הסר פרסומות"** במסך הסיום מציג רק בדיחה; הפרסומות לא מתבטלות. הספירה משותפת למשחקים שמריצים את המודול באותו דפדפן ובאותו מזהה שחקן.

## טכנולוגיה

אתר סטטי יחיד ב-HTML, Canvas ו-JavaScript, ללא שרת או ספריית UI; טוען רק את סקריפט הפרסומות המשותף. תמונות הפנים והדמויות הוטמעו ב-HTML כדי שהמשחק יפעל גם כשהרשת איטית.

## פרטיות

אין איסוף של מספרי טלפון או פרטי משתמשים. בחירת הדמות, הגדרות הצליל, שיאי הניקוד ומוני פסילות/צפיות בפרסומות נשמרים ב-localStorage של המכשיר. הטבלה אינה משותפת בין לקוחות.

# 💈 מרוץ המספרה — אבי × קוקו

משחק ריצה אינסופית למובייל בהשראת הז'אנר של Temple Run, בכיכוב הספרים אבי וקוקו.

## משחקים
- בחרו **אבי** (ספר הנשים) או **קוקו** (ספר הגברים), ולחצו **יאללה לרוץ!**.
- החליקו ימינה או שמאלה כדי לעבור בין שלושה נתיבים.
- החליקו למעלה כדי לקפוץ מעל כיסאות.
- החליקו למטה כדי להתכופף מתחת לשלטים.
- התחמקו מעגלות ציוד, אספו מטבעות, ונסו לשבור את השיא.
- אפשר גם להשתמש בכפתורי המגע הקבועים בתחתית המסך או במקלדת.
- יש שלוש פסילות (לבבות) לכל ריצה, ואפשר לעצור ולהמשיך.

בהגדרות הרפו: Settings → Pages → Deploy from a branch → main → /(root) → Save.

האתר עובד ללא שרת וללא התקנות. תמונות הפנים של אבי וקוקו מוטמעות בקובץ HTML, והציון והשיאים נשמרים רק בדפדפן שבו משחקים.

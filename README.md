## איך משחקים

1. בוחרים לשחק בתור אבי (ספר הנשים) או קוקו (ספר הגברים).
2. לוחצים על **יאללה לרוץ**.
3. מחליקים ימינה או שמאלה כדי לעבור נתיב; למעלה כדי לקפוץ; למטה כדי להתכופף.
4. אפשר גם ללחוץ על ארבעת הכפתורים בתחתית המסך.
5. קופצים מעל כיסאות, מתכופפים מתחת למחסומי המספריים, ומתחמקים מעגלות הספר.
6. אוספים מטבעות; מתחילים עם שלושה לבבות. הניקוד והשיא נשמרים בדפדפן.

## טכנולוגיה

אתר סטטי יחיד ב-HTML, Canvas ו-JavaScript, ללא ספריות חיצוניות או שרת. תמונות הפנים והדמויות הוטמעו ב-HTML כדי שהמשחק יפעל גם כשהרשת איטית.

## פרטיות

אין איסוף של מספרי טלפון או פרטי משתמשים. רק בחירת הדמות, הגדרות הצליל ושיאי הניקוד נשמרים ב-localStorage של המכשיר. הטבלה אינה משותפת בין לקוחות.

הגדרת GitHub Pages: `Settings → Pages → Deploy from a branch → main → /(root) → Save`. אחרי הגדרת Pages, המשחק פועל בכתובת למעלה.

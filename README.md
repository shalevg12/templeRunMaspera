# בריחה מהמספרה — אבי × קוקו 🏃✂️

משחק ריצה אינסופית למובייל, באווירת משחקי הריצה Temple Run, עם פרצופי אבי וקוקו מהמספרה. המשחק מקורי ועצמאי, ללא קבצים חיצוניים או ספריות.

## לשחק

כתובת המשחק לאחר הפעלת GitHub Pages: https://shalevg12.github.io/templeRunMaspera/

שלט QR להדפסה: https://shalevg12.github.io/templeRunMaspera/qr.html

## הפעלה

- בוחרים אבי (ספר הנשים) או קוקו (ספר הגברים), ואז לוחצים **יאללה לרוץ!**
- מחליקים ימינה או שמאלה כדי לעבור בין שלושה נתיבים.
- מחליקים למעלה כדי לקפוץ מעל כיסא הספרים.
- מחליקים למטה כדי להתכופף מתחת לשלט נמוך.
- מחליפים נתיב כדי להתחמק מעגלת הציוד, ואוספים מטבעות.
- אפשר גם להשתמש בכפתורים המוצגים בתחתית המסך, או בחיצי המקלדת.
- לחצן ההשהיה בפינה העליונה מאפשר להמשיך, להתחיל מחדש או לבחור דמות אחרת.

## פרסום

1. פתחו את [Settings → Pages](https://github.com/shalevg12/templeRunMaspera/settings/pages).
2. בחרו `Deploy from a branch`, ואז `main` ו־`/(root)`.
3. שמרו. לאחר שהפרסום מסתיים המשחק זמין בכתובת למעלה.

## פרטיות

אפשר לשחק כאורח בלי להירשם. יש הרשמה מקומית אופציונלית בשם ומספר טלפון **בלי OTP וללא סיסמה**. זוהי **לא התחברות מאובטחת**: כל הנתונים נשמרים אך ורק ב־localStorage של אותו דפדפן, ולא נשלחים לשרת ולא משותפים בין מכשירים. אין להשתמש במנגנון הזה לזיהוי לקוחות, ניהול פרסים או טבלת ניקוד משותפת.
